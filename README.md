# Polisportiva A.V.I. – Prototype of the new website

Interactive prototype of the new trilingual website (Deutsch, Italiano, English) for the swimming section of ASD Polisportiva A.V.I. Vipiteno/Sterzing.

**What you can try**
- Home page with a "lane" for every type of swimmer and a DE / IT / EN language switch
- Course list with filters by age and day, free spots and remaining lessons
- 4-step sign-up with age check, consents and payment choice, plus a waitlist for full courses
- Swim school, Team, Club, News and Contact pages
- Admin panel preview: overview, automatic date checks, date generator, trilingual notices

Courses are those published for autumn 2026; free spots, some times and all admin figures are sample data. This prototype is not indexed by search engines.

Prepared by Hessam and developer team.
